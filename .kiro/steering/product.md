# Product Overview

## 阅影·log (YueYing)

An AI-driven personal entertainment tracking platform for movies, TV shows, anime, games, and books.

## Core Features

- **Content Management**: Track and organize movies, TV shows, anime, games, and books with status tracking (want to watch/read, watching/reading, completed)
- **AI-Powered Tagging**: Automatic tag generation based on content descriptions and user notes using LLM
- **Personalized Recommendations**: Hybrid recommendation engine combining collaborative filtering and content-based algorithms
- **AI Assistant**: RAG-based conversational assistant for querying history, generating summaries, and getting recommendations
- **Statistics & Analytics**: Comprehensive data visualization and insights about viewing/reading habits
- **Admin Dashboard**: System management, user management, LLM configuration, and API key management

## External Data Sources

- **TMDB**: Movies and TV shows
- **Google Books**: Book information
- **Bangumi (番组计划)**: Anime, games, and Chinese ACG content (replaces AniList and Douban)

## Privacy-First

This is a personal tool designed for individual use with complete data privacy. All data is stored locally in the user's own infrastructure.

## Target Users

Individuals who want to:
- Keep detailed records of their entertainment consumption
- Get AI-powered insights and recommendations
- Maintain a private, organized collection
- Generate periodic summaries and reviews
