## 🎨 设计理念

### 设计原则

1. **AI能力可见化** - 将AI功能从幕后带到台前
2. **数据驱动决策** - 用可视化帮助用户理解自己的观影习惯
3. **简洁高效** - 减少操作步骤,提升核心流程效率
4. **响应式设计** - 移动端和桌面端一致的体验

### 设计系统

**色彩方案**
- 主色调: 紫色系(#7C3AED) - 代表AI智能
- 辅助色: 蓝色系(#3B82F6) - 电影/剧集
- 强调色: 粉色系(#EC4899) - 动画/游戏
- 中性色: 灰度系 - 适配暗黑/明亮主题

**排版规范**
- 标题: Inter/思源黑体 Bold
- 正文: Inter/思源黑体 Regular
- 代码/数据: JetBrains Mono

#### 搜索逻辑流程

```typescript
// hooks/useSearch.ts
export function useSearch() {
  const [mode, setMode] = useState<'ai' | 'keyword'>('keyword');
  const [query, setQuery] = useState('');
  const [filters, setFilters] = useState({
    contentType: 'all',
    yearRange: [1990, 2024],
  });

  const { data, isLoading } = useQuery({
    queryKey: ['search', mode, query, filters],
    queryFn: async () => {
      if (!query) return [];

      if (mode === 'ai') {
        // AI语义搜索
        const response = await ragApi.search({
          query,
          content_type: filters.contentType !== 'all' ? filters.contentType : undefined,
          limit: 50,
        });
        return response.data;
      } else {
        // 普通关键词搜索
        const response = await unifiedSearchApi.search({
          query,
          content_type: filters.contentType !== 'all' ? filters.contentType : undefined,
          year_from: filters.yearRange[0],
          year_to: filters.yearRange[1],
        });
        return response.data;
      }
    },
    enabled: query.length > 0,
  });

  // 默认按时间倒序排序
  const sortedResults = useMemo(() => {
    if (!data) return [];
    return [...data].sort((a, b) => 
      new Date(b.created_at).getTime() - new Date(a.created_at).getTime()
    );
  }, [data]);

  return {
    mode,
    setMode,
    query,
    setQuery,
    filters,
    setFilters,
    results: sortedResults,
    isLoading,
  };
}
```

### WebSocket集成(AI助手)

```typescript
// lib/websocket.ts
import { io, Socket } from 'socket.io-client';

class WebSocketService {
  private socket: Socket | null = null;

  connect(token: string) {
    this.socket = io(process.env.NEXT_PUBLIC_WS_URL!, {
      auth: { token },
      transports: ['websocket'],
    });

    this.socket.on('connect', () => {
      console.log('WebSocket connected');
    });

    this.socket.on('message', (data) => {
      // 处理AI流式响应
      this.handleMessage(data);
    });
  }

  sendMessage(content: string) {
    this.socket?.emit('chat', { content });
  }

  disconnect() {
    this.socket?.disconnect();
  }

  private handleMessage(data: any) {
    // 更新助手store
    useAssistantStore.getState().appendMessage(data);
  }
}

export const wsService = new WebSocketService();
```
