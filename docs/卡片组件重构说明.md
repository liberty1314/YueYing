# 卡片组件重构说明

## 重构目标

将所有媒体资源卡片组件从"嵌套布局"重构为 Netflix/Apple TV 风格的"分离布局"。

## 核心改进

### 1. 结构分离

**之前的结构：**
```jsx
<Card>
  <ImageSection />
  <InfoSection /> {/* 在 Card 内部 */}
</Card>
```

**重构后的结构：**
```jsx
<Wrapper>
  <Card>
    <ImageSection /> {/* 纯图片卡片 */}
  </Card>
  <InfoSection /> {/* 独立的信息区域 */}
</Wrapper>
```

### 2. 样式特点

#### 图片卡片（上半部分）
- 独立的 Card 组件，带圆角和阴影
- 固定长宽比 2:3（适合电影海报）
- Hover 效果：阴影加深 + 轻微上浮 + 图片放大
- 图片使用 `object-cover` 填充整个区域

#### 信息区域（下半部分）
- 透明背景，直接显示在页面背景上
- 与图片卡片保持 `mt-2` 间距
- 包含标题（加粗，最多 2 行）
- 包含元数据行（年份在左，评分在右）

### 3. 视觉效果

- 图片卡片有明确的边界和阴影，视觉上更突出
- 信息区域简洁，不抢夺图片的视觉焦点
- 整体布局更接近 Netflix/Apple TV 的设计风格

## 重构的组件

## 技术细节

### 响应式布局
所有卡片组件都支持响应式网格布局：
```jsx
<div className="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 xl:grid-cols-6 gap-4">
  <SearchResultCard ... />
  <ContentCard ... />
  ...
</div>
```

### 暗黑模式支持
- 图片卡片背景：`bg-gray-200 dark:bg-gray-800`
- 文字颜色：`text-gray-900 dark:text-white`
- 元数据颜色：`text-gray-500 dark:text-gray-400`

### Hover 交互
- 图片卡片：`hover:shadow-xl hover:-translate-y-1`
- 图片放大：`group-hover:scale-105`
- 遮罩层显示：`opacity-0 group-hover:opacity-100`

## 使用示例

### 搜索页面
```tsx
import { SearchResultCard } from '@/components/features/search/SearchResultCard';

<div className="grid grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-5 gap-4">
  <SearchResultCard
    result={searchResult}
    viewMode="grid"
    onView={(result) => console.log('View:', result)}
    onAdd={(result) => console.log('Add:', result)}
  />
</div>
```

### 库页面
```tsx
import { ContentCard } from '@/components/features/library/ContentCard';

<div className="grid grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-5 2xl:grid-cols-6 gap-6">

```

## 注意事项

1. 所有卡片组件都已从 MUI 迁移到 Tailwind CSS
2. 图片和信息区域是兄弟元素，不是父子关系
3. 信息区域的背景是透明的，会显示页面背景色
4. 评分从图片右上角移到了信息区域的右侧

- ✅ **首页** (`/`) - 热门推荐、AI 推荐、分类推荐
