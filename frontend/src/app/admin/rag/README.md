# RAG 管理页面

## 概述

RAG（检索增强生成）管理页面用于管理向量数据库和索引，是 AI 助手功能的核心基础设施。

## 功能特性

### 1. 向量存储统计

显示向量数据库的关键统计信息：
- **索引项目总数**: 已索引的用户项目数量
- **集合名称**: ChromaDB 集合名称
- **向量维度**: 嵌入向量的维度（384 维）

### 2. 索引重建

提供重建向量索引的功能：
- 重新计算所有用户项目的向量嵌入
- 适用于首次启用 RAG、更换模型、数据异常等场景
- 显示重建进度和状态反馈

### 3. 配置信息

显示 RAG 系统的配置信息：
- **嵌入模型**: paraphrase-multilingual-MiniLM-L12-v2
- **向量数据库**: ChromaDB
- **相似度阈值**: 0.01

## 技术实现

### 组件结构

```
RAGManagementPage
├── StatCard (统计卡片)
├── EmptyState (空状态)
├── ErrorState (错误状态)
└── 配置和操作区域
```

### API 集成

使用 React Query hooks：
- `useVectorStoreStats()`: 获取向量存储统计信息
- `useRebuildIndex()`: 重建向量索引

### 状态管理

- 使用 React Query 管理服务器状态
- 本地状态管理重建进度
- 自动刷新统计信息（30 秒间隔）

## 设计特点

### Apple 风格设计

- 使用 AppleCard 组件展示信息
- 毛玻璃效果和柔和阴影
- 平滑的悬停动画
- 清晰的视觉层次

### 响应式布局

- 桌面：3 列网格布局
- 平板/移动：单列布局
- 自适应卡片尺寸

### 用户反馈

- 加载状态：Skeleton 占位符
- 空状态：友好的提示和引导
- 错误状态：清晰的错误信息和重试按钮
- 成功/失败：Toast 通知

## 使用场景

### 首次启用 RAG

1. 访问 RAG 管理页面
2. 查看空状态提示
3. 点击"重建索引"按钮
4. 等待索引构建完成
5. 查看统计信息确认成功

### 定期维护

1. 查看索引项目总数
2. 确认与实际数据一致
3. 如有异常，重建索引

### 故障排查

1. 检查错误状态提示
2. 查看统计信息是否正常
3. 尝试重建索引
4. 查看后端日志获取详细信息
