# 前端页面跳转性能优化

## 优化内容

### 1. React Query 缓存优化
**文件**: `frontend/app/providers.tsx`

- `staleTime`: 1分钟 → 5分钟（数据保持新鲜的时间）
- `gcTime`: 新增 10分钟（缓存保留时间）
- `refetchOnMount`: 新增 false（有缓存时不重新请求）
- `refetchOnReconnect`: 新增 false（网络重连时不自动请求）

**效果**: 页面跳转时优先使用缓存数据，减少不必要的 API 请求

### 2. Next.js 性能配置
**文件**: `frontend/next.config.js`

- 启用 `swcMinify: true`（使用更快的 SWC 压缩）
- 添加 `optimizePackageImports`（优化 lucide-react 等包的导入）
- 优化 webpack fallback 配置

**效果**: 构建速度更快，包体积更小

### 3. API 请求去重
**文件**: `frontend/lib/api.ts`

- 添加请求去重机制（pendingRequests Map）
- 相同的 GET 请求同时发起时，复用同一个 Promise
- 请求完成后自动清理缓存

**效果**: 防止重复请求，减少服务器压力

### 4. 路由级别 Loading 状态
**新增文件**:
- `frontend/app/library/loading.tsx`
- `frontend/app/stats/loading.tsx`
- `frontend/app/discover/loading.tsx`
- `frontend/app/assistant/loading.tsx`
- `frontend/app/admin/loading.tsx`

**效果**: 页面跳转时立即显示骨架屏，提供即时反馈

### 5. Library 页面优化
**文件**: `frontend/app/library/page.tsx`

- 使用 React Query hooks 替代本地状态管理
- 使用 `useMemo` 优化 filters 计算
- 自动缓存和失效管理
- 更流畅的数据更新体验

**新增文件**: `frontend/hooks/use-user-items.ts`
- 统一的 React Query hooks
- 自动缓存失效策略
- 更好的类型支持

**效果**: 
- 页面切换回来时使用缓存数据，无需重新加载
- 删除/更新操作后自动刷新相关数据
- 更少的状态管理代码

## 预期效果

1. **首次访问**: 正常加载速度
2. **再次访问**: 
   - 5分钟内：直接使用缓存，瞬间显示
   - 5-10分钟：显示缓存数据，后台更新
   - 10分钟后：重新请求数据
3. **页面跳转**: 显示 loading 状态，无白屏
4. **重复请求**: 自动去重，减少网络开销

## 测试建议

1. 清除浏览器缓存后测试首次加载
2. 在不同页面间快速切换，观察是否流畅
3. 检查 Network 面板，确认请求是否减少
4. 观察 loading 状态是否正常显示
